# BM25 baseline

A lexical floor: Okapi BM25 over every written event, pure Python, offline, no
extra to install.

```bash
membench run --backend bm25 --pack customer-support --no-judge
```

- Tokens are lowercase `\w+` runs; idf is `log(1 + (N - df + 0.5) / (df + 0.5))`.
- Recall returns the top-k events with a positive score, best first (ties keep
  write order); the context is their text, one per line, without timestamps.
- `forget` drops the event; `reset` clears the index.

| Key | Default |
|---|---|
| `top_k` | 3 |
| `k1` | 1.5 |
| `b` | 0.75 |

Any memory backend that scores below `bm25` on a pack is losing to keyword
matching.
